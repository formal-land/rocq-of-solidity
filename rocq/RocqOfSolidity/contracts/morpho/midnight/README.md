# Morpho Midnight

This folder contains shallow Rocq embeddings generated from the unoptimized Yul
for Morpho Midnight.

- Source repository: https://github.com/morpho-org/midnight.git
- Source commit: `7538c438513622721e23a94676b93a335b83dace`
- Submodule path: `deps/midnight`
- Solidity compiler used for extraction: `solc 0.8.34`
- EVM version: `osaka`

The generated files intentionally use unoptimized Yul. The extraction uses
`--ir` and `--ir-ast-json` without `--optimize`, `--optimize-runs`, or
`--ir-optimized-ast-json`.

## Layout

Each generated object folder contains:

- `contract.yul`: unoptimized Yul emitted by `solc`
- `contract.json`: unoptimized Yul AST JSON, filtered to remove source metadata
- `shallow.v`: shallow Rocq embedding generated by `rocq/scripts/shallow_embed.py`

Interface-only source files are compilation dependencies. At this commit, `solc`
emits `null` Yul AST objects for those interfaces, so there is no corresponding
`shallow.v` for them.

The Solidity snapshot under `core/midnight/solidity-src` matches the pinned
submodule’s `src` directory. Its license texts are in
[`deps/midnight/LICENSE`](../../../../../deps/midnight/LICENSE) and
[`deps/midnight/LICENSE-SECONDARY`](../../../../../deps/midnight/LICENSE-SECONDARY).

## Reproduction

From the repository root:

```sh
/tmp/solc-0.8.34 --ir --ir-ast-json --evm-version osaka -o /tmp/midnight-solc-out $(find deps/midnight/src -name '*.sol')
```

For each non-null object:

```sh
jq 'walk(if type == "object" then del(.nativeSrc, .src, .type) else . end)' \
  /tmp/midnight-solc-out/<Name>_yul_ast.json > contract.json
python3 rocq/scripts/shallow_embed.py contract.json > shallow.v
```

The core functional specification is in `core/midnight/functional_spec.v`.
The corresponding proofs are in `functional_equivalence.v` and the
`solidity_equivalence_*.v` files alongside it.
